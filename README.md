# مساعد ترتيب الرغبات

إضافة تجريبية لـ Chrome/Chromium لمنصة concours.onec.dz. تعتمد على رموز المؤسسات، وتبقي الحفظ والتأكيد يدوياً.

## ملفات التخصص

يوجد ملف مستقل للغة العربية في الطور الابتدائي داخل `data/arabe-primaire.json`. لا تخلط بيانات التربية البدنية والرياضية مع هذا الملف؛ يجب تعبئته من حساب اللغة العربية نفسه لأن القائمة تختلف حسب الرتبة والمادة.
